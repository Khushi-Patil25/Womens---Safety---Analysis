# Women's Safety Analysis Dashboard

## Project Overview
This project analyzes crimes against women in India from 2001 to 2012.
The objective is to identify crime trends, understand crime categories,
compare states and union territories, and highlight patterns in the data.

## Objectives
- Analyze year-wise crime trends.
- Identify the most reported crime categories.
- Compare crimes across states and union territories.
- Examine changes in reported crime counts over time.
- Present key findings through an interactive Power BI dashboard.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- MySQL
- SQL
- Microsoft Power BI

## Project Files
- `womens_safety_analysis.py` — Python analysis and visualizations.
- `crcCAW_r1.csv` — Dataset used for the analysis.
- `Womens safety analysis.sql` — SQL queries.
- `WOMEN Safety Analysis dashboard.pbix` — Power BI dashboard.
- Dashboard-related CSV files — Supporting analysis data.

## Analysis Performed
- Year-wise crime trend analysis.
- Crime category analysis.
- State-wise comparison.
- Crime risk-level classification.
- Identification of the top five states/UTs by reported crime counts.

## Dataset Period
2001–2012

## Important Note
This project analyzes historical reported crime data. Reported counts do not
necessarily represent the actual prevalence of crime or the overall safety
level of a state. Risk classifications are analytical categories used in this
project, not official safety ratings.
